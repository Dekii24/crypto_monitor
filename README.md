# crypto_monitor

This project is designed as a practical demonstration of modern DevOps practices and cloud-native software development. The backend is powered by a C# (.NET) Minimal API that fits seamlessly into a microservices architecture and communicates with external services.

The application is fully containerized. Code integration, testing, and deployment are managed by a fully automated GitHub Actions CI/CD pipeline, ensuring fast, reliable version control and continuous delivery. The user-facing application is a cryptocurrency price tracker that automatically fetches and updates the displayed exchange rates at regular intervals.
